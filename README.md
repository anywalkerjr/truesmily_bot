# 🎰 Smily Telegram Bot

Smily — это многофункциональный игровой и экономический Telegram-бот, объединяющий в себе азартные мини-игры, RPG-элементы (прокачка уровня, таланты), пассивный заработок и PvP-взаимодействие между игроками. 

Бот написан на Python с использованием библиотеки `python-telegram-bot` и базы данных MySQL.

## 🚀 Основные возможности

### 🎮 Игры (Динамическая генерация изображений)
Все игры сопровождаются красивыми визуальными карточками, которые генерируются "на лету" с помощью библиотеки Pillow:
* **Crash (`/crash`)** — классическая игра со взлетающей ракетой (поддерживает соло и мультиплеер в чате).
* **Слоты (`/spin`)** — крути барабаны и лови джекпоты (777).
* **Mines (`/mines`)** — сапер на деньги. Открывай безопасные клетки и вовремя забирай выигрыш.
* **Blackjack (`/bj`)** — карточная классика против дилера.
* **Рулетка (`/rt`)** — ставки на числа, цвета и дюжины.
* **Башня (`/tower`)** — пробирайся наверх, угадывая безопасные блоки.

### 💰 Экономика и RPG
* **Бизнесы (`/shop`)** — покупай предприятия (от ларька с шаурмой до Космической компании) и получай пассивный доход + уникальные баффы.
* **Таланты (`/talents`)** — прокачивай навыки (Удача, Ловкость, Мастерство, Неприкасаемость), чтобы получать кэшбэк при проигрышах или увеличивать заработок опыта.
* **Система уровней** — играй, копи EXP, повышай уровень и открывай новые бизнесы и таланты.
* **Банковские вклады (`/deposit`)** — замораживай средства под процент.
* **Кейсы (`/cases`)** — лутбоксы с гемами, балансом и опытом (включая бесплатный кейс каждые 45 минут!).

### ⚔️ Социальное взаимодействие (PvP)
* **Дуэли (`/duel`)** — бросай вызов другим игрокам на деньги (кости, дартс, баскетбол и др.).
* **Кражи (`/steal`)** — попытайся обворовать друзей в чате (учитывает прокачку талантов и защиты).
* **Взлом банка (`/hack`)** — шанс для тех, кто проиграл всё. Можно попытаться хакнуть систему, если твой баланс равен нулю.
* **Донат (`/stars`)** — легальная внутриигровая покупка опыта за Telegram Stars.

## 🛠 Технический стек
* **Язык:** Python 3.10+
* **Фреймворк:** `python-telegram-bot` (v20+)
* **База данных:** MySQL (с использованием `mysql-connector-python` Connection Pooling)
* **Графика:** `Pillow` (PIL) для генерации интерфейсов на лету
* **Архитектура:** Асинхронная, с защитой от Race Conditions (атомарные SQL-транзакции) и локальным анти-флуд троттлингом (Debouncer) для защиты Telegram API от спам-кликов.
